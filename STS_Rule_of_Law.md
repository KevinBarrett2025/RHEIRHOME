# STS Rule of Law

## Highest Priority Rules
1. Repo state is truth.
2. Build/test gates are mandatory.
3. Scope is locked to the approved objective.
4. Unrelated user edits must be preserved.
5. Promotion law applies even if promotion is not currently in scope.

## Repo-Local Interpretation
- This repository does not currently include the original STS document set.
- The repo-local docs created here are the governing workflow documents for this repo until replaced by an explicitly approved canonical set.
- Any future thread must read these docs before continuing implementation or release work.
